# VentureOS submission archive (historical)

**VentureOS was the original Microsoft Build AI / HackerEarth submission name. The product was subsequently renamed Foundry.**

This folder preserves the original hackathon submission artifacts exactly as
they were created under the **VentureOS** name. Their filenames and visible
branding are intentionally left unchanged — they are historical records of the
submission and must not be edited or re-branded.

## Contents

| File | What it is |

| [`screenshots/`](./screenshots/) | Original, dated screenshots of the deployed product as VentureOS |

## Notes

- **Do not modify these files.** They are the as-submitted VentureOS artifacts.
- Current, Foundry-branded materials belong elsewhere in the repository. A
  Foundry-branded deck and freshly captured Foundry screenshots are pending and
  should be added under the active docs (not here) once produced.
